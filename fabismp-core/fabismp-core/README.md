# fabismp-core (Paper 26.2, Java 25)

Build: `./gradlew build` (Gradle Wrapper ggf. mit `gradle wrapper` erzeugen) -> `build/libs/fabismp-core.jar`
Jar in `plugins/` legen, Server starten, `plugins/FabiSMP-Core/config.yml` anpassen.

Commands: /bal /pay /baltop /sell [hand|all] /worth /shards /eco /rtp /tpa /tpaccept /tpdeny /home /sethome /delhome /homes /stats
Combat-Log: Kampf-Tag bei PvP, Logout = Tod, gesperrte Befehle (config: combat.*)
Admin: fabismp.admin
